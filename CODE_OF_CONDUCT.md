# Code of Conduct

`django-db-mailer` is a small, single-maintainer open-source project.
Its community standards are correspondingly simple.

## What we expect

- **Be respectful.** Disagree with ideas, not with people.
- **Stay on topic.** Issues and Discussions are about django-db-mailer
  and its users — keep unrelated debates elsewhere.
- **Be patient.** Maintainer time is volunteer time; replies can take
  days, not minutes. A polite ping after a week is fine; daily nags
  are not.
- **Help newcomers.** Most people who file an unclear issue are not
  trying to waste anyone's time — they have not read MIGRATION.md
  yet. Point them to it kindly.
- **Credit prior work.** When proposing a change, mention the
  alternatives you considered and the projects that inspired you.

## What is out of bounds

- Personal attacks, name-calling, doxxing.
- Spam, off-topic promotion of unrelated services.
- Repeatedly reopening issues that the maintainer has closed with a
  documented decision.
- Bypassing the security policy by posting suspected vulnerabilities
  in public issues — use a private GitHub Security Advisory instead.

## Enforcement

The maintainer reserves the right, without further notice, to:

- edit or remove comments, issues and pull requests that conflict
  with the rules above;
- block contributors who repeatedly violate them;
- close issues that have stalled for more than 90 days without new
  information.

If you think a maintainer's action is unfair, send a calm, factual
note to **gotlium@gmail.com**. Disputes are resolved off-list.

## Scope

This applies to every space that represents the project: the
GitHub repository, GitHub Discussions, the public issue tracker,
and any official social-media account or chat that may exist.

It does not regulate behaviour outside those spaces.
